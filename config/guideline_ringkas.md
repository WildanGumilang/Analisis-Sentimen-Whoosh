# Guideline Ringkas (pegangan saat melabeli)

**Relevan = ya** hanya jika ada opini tentang akses/transportasi **menuju atau dari** stasiun.
Hal-hal berikut diabaikan: kereta, kebersihan, toilet, petugas, tiket kereta, makanan, dan fasilitas di dalam stasiun.

| Kode | Isi |
|---|---|
| FEEDER_BUS | shuttle, DAMRI, TMP, Teman Bus, travel, halte |
| PADALARANG | turun di Padalarang, KA Feeder, kereta ke Stasiun Bandung |
| OJOL | Gojek/Grab/Maxim/inDrive, titik jemput, drop-off |
| TAKSI | taksi, Bluebird, argo |
| ANGKOT_OJEK_PANGKALAN | angkot, opang, calo |
| PARKIR | parkir, parkir inap, valet, antar-jemput pribadi |
| AKSES_JALAN_MACET | macet, jalan, tol, putar balik |
| JARAK_LOKASI | jauh/dekat dari kota atau tujuan |
| INTEGRASI_JADWAL | jadwal, jam operasional, waktu tunggu, sinkron dengan kereta |
| KONEKTIVITAS_UMUM | akses umum tanpa moda ("susah pulang", "transportasinya minim") |

**Sentimen**
- positive / negative / neutral (fakta tanpa penilaian) / mixed (satu aspek baik sekaligus buruk)
- Sarkasme dinilai sesuai maksud. Saran perbaikan → negative. Pertanyaan → neutral.
- **Jangan melihat bintang.**

**Aturan cepat**
- Satu review boleh punya beberapa aspek, masing-masing dengan sentimennya sendiri.
- Evidence = blok sesingkat mungkin yang tetap bermakna (± satu klausa).
- "Mending turun Padalarang" → PADALARANG pos + KONEKTIVITAS_UMUM/JARAK_LOKASI neg.
- Kalau tidak yakin, **centang ragu**.
- "Dekat X" deskriptif → JARAK_LOKASI neutral · daftar moda ("ada Damri, taksi") → neutral per moda
- "Akses" tanpa moda → KONEKTIVITAS_UMUM (kalau review bahas jalan/tol/macet → AKSES_JALAN_MACET)
- Drop-off/antar-jemput pribadi → PARKIR · "feeder" dibanding Padalarang (KA feeder) → KONEKTIVITAS_UMUM
